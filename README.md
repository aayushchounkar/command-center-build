# Project Nexus

Build a premium, hackathon-ready personal portfolio website for me using the resume I have attached as the single source of truth for my personal information, education, experience, projects, skills, achievements, and contact details.

CORE OBJECTIVE

Create a portfolio that feels like a premium product launch + superhero command center, not a normal student portfolio.

The website should immediately communicate:

“This person builds, leads, solves problems, and gets things done.”

Take creative inspiration from the cinematic feel of Marvel/Avengers interfaces, Iron Man HUDs, futuristic command centers, and high-end tech product websites, but DO NOT directly copy Marvel/Avengers copyrighted logos, characters, artwork, or UI.

The final website should be something I can confidently showcase at a hackathon, interview, networking event, or to recruiters.

Overall aesthetic:

Premium

Cinematic

Futuristic

Dark

Minimal but visually powerful

Tech-focused

Executive/student-leader personality

High-end startup/product aesthetic

Think:

Iron Man HUD × Apple-level polish × modern SaaS × futuristic AI dashboard

Use a dark background with:

Thin glowing borders

Do NOT make it look like a gaming website.

It should feel sophisticated enough for a Project Manager / Product / Technology / Business role.
